The first start

The builds aren't signed by Apple or Microsoft yet, so the first start needs one extra step.

Mac

  1. Download the Mac download, open it and drag Rip It Out to Applications.
  2. macOS blocks the first start ("damaged" or "can't be opened"). Run this once in Terminal: 
    xattr -dr com.apple.quarantine "/Applications/Rip It Out.app"
  3. Start Rip It Out. The first song takes a little longer while the app fetches what it needs (once).

For Macs with an Apple chip (M1 or newer). Updates install from Settings.

Windows

  1. Download the Windows download and run it. It installs for your user, no administrator rights needed.
  2. SmartScreen says "Windows protected your PC": click More info, then Run anyway.
  3. With an NVIDIA graphics card, keep GPU acceleration ticked: new songs are ready much faster.

For Windows 10 and 11. To update, install the new version over the old one.
