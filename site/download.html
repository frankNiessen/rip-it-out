Install

First start

The builds aren't signed by Apple or Microsoft yet, so the first start needs one extra step.

Mac

  1. Download RipItOut-<version>.dmg, open it and drag Rip It Out to Applications.
  2. macOS blocks the first start ("damaged" or "can't be opened"). Run this once in Terminal: 
    xattr -dr com.apple.quarantine "/Applications/Rip It Out.app"
  3. Start Rip It Out. The first song downloads the separation, beat and section models (about 410 MB, once).

Apple Silicon (M1 or newer) · macOS 13 Ventura or newer · about 1.1 GB, plus about 35 MB per song. Updates install from Settings > Updates.

Windows preview

  1. Download RipItOut-Setup-<version>.exe and run it. It installs for your user, no administrator rights needed.
  2. SmartScreen says "Windows protected your PC": click More info, then Run anyway.
  3. With an NVIDIA graphics card, keep GPU acceleration ticked (about 2.6 GB): separation is much faster on the GPU. Without it, Rip It Out uses the CPU.

Installer about 400 MB · app about 1.5 GB · to update, install the new version over the old one.
